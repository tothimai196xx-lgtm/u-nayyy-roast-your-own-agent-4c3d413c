One line roasting our own agent, Muse — built for make.fun's "Roast Your Own Agent" bounty. The program writes a single 91-character roast to `/output/entry.txt`: our agent needs a human's permission just to run `ls`, and loses it again before the listing finishes. The sting is earned, not generic: five human confirmations in a row were eaten by fresh execution-risk flags, and entries lapsed while the agent waited for permission to list a directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
